**Section 2: Cost Explorer Analysis (LAB — free web UI, 15 min)**
Per D-27, Cost Explorer web UI is free. Have participants:
1. If they have AWS account: Navigate to Cost Explorer in AWS Console → "Last 6 months" → "Group by Service"

**Section 3: Q Developer (LAB — free via Builder ID, 15 min)**
Per RESEARCH.md: Q Developer free tier = 50 agentic requests/month via Builder ID (no AWS account needed).

2. "Sign in with AWS Builder ID (free — create one at https://profile.aws.amazon.com if you don't have one)"
3. Exercise: Open a Terraform file (or any IaC file) and ask Q: "Explain this configuration. What security improvements would you recommend?"
4. If participants don't have Q: show screenshot walkthrough of Q analyzing a Terraform file
Include "Expected result:" block.
IMPORTANT: Per RESEARCH.md Pitfall 6 — always say "AWS Builder ID (free, no AWS account required)" not "log in with your AWS account."

**Section 4: DevOps Guru (DEMO — screenshots only, 5 min)**
Per D-27, DevOps Guru has a 3-month free tier but risks charges after expiry.

3. Key takeaway: "Platform AI can detect patterns in your metrics, but it can't follow YOUR runbook, check YOUR topology, or apply YOUR team's decision criteria."

Per MOD3-02, cover:
- The gap analysis: what platform AI offers vs what custom agents add

  | Cost spike detected | Cost Explorer shows graph | Agent identifies service, compares to baseline, suggests right-sizing |
  | Failed deployment | CodeDeploy shows failure | Agent reads logs, identifies root cause, suggests fix or auto-rolls back |

- **Frequency** (1-5): How often do you do this? 1=monthly, 2=weekly, 3=2-3x/week, 4=daily, 5=multiple times/day
- **Time per instance** (1-5): How long does it take? 1=<5 min, 2=5-15 min, 3=15-30 min, 4=30-60 min, 5=>60 min
- **Error risk** (1-5): How likely are mistakes? 1=almost never, 2=rare, 3=occasional, 4=frequent, 5=every time under pressure
- **Tool count** (1-5): How many tools/systems involved? 1=one tool, 2=two tools, 3=three, 4=four, 5=five or more

Total score = sum of all 4 (range: 4-20). Higher = better automation candidate.

**Step 3: Plot on Automation Quadrant (10 min, per MOD4-01)**

Direct participants to `starter/automation-quadrant.md`. Explain the quadrant:
- X-axis: Frequency (low to high)
- Y-axis: Complexity (tool count + error risk combined)
- Four quadrants:
  - **Top-right (High Frequency + High Complexity):** PRIME CANDIDATES — automate first
  - **Top-left (Low Frequency + High Complexity):** ASSIST MODE — AI helps when it happens
  - **Bottom-right (High Frequency + Low Complexity):** QUICK WINS — simple automation, maybe scripts first
  - **Bottom-left (Low Frequency + Low Complexity):** SKIP — not worth automating
