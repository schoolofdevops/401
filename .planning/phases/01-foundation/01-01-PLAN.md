Build the three Rust backend microservices for the course reference application: api-gateway (port 8080), catalog (port 8081), and worker (port 8082), plus PostgreSQL migration SQL and Docker images.

Purpose: These services are the backbone of every lab in the course. They demonstrate K8s patterns (health checks, inter-service dependencies, graceful degradation), generate real PostgreSQL queries for database agent labs, and provide natural failure modes for observability exercises. Per D-05, participants never modify Rust code directly — they interact via APIs, Helm charts, K8s manifests, and CI/CD pipelines.

Output: A Cargo workspace with three compilable, testable Rust services, each with a Dockerfile, plus a shared library crate and PostgreSQL init migration.

    -- Used by: catalog (reads), worker (writes), database agents (Module 10)

    CREATE TABLE IF NOT EXISTS items (
        id SERIAL PRIMARY KEY,
        name VARCHAR(255) NOT NULL,
        description TEXT,
        status VARCHAR(50) NOT NULL DEFAULT 'active',
        created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    );

        id SERIAL PRIMARY KEY,
        source VARCHAR(100) NOT NULL,
        event_type VARCHAR(100) NOT NULL,
        payload JSONB NOT NULL DEFAULT '{}',
        created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
    );

        ('notification-service', 'Email and SMS notifications', 'degraded'),
        ('data-pipeline', 'ETL pipeline for analytics', 'active')
