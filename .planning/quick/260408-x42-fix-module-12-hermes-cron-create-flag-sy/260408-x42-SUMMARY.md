# Quick Task 260408-x42: Summary

## Bug

Running Lab 12 Step 2 produced:
```
hermes: error: unrecognized arguments: --schedule --prompt Run daily Kubernetes cluster health check...
```

## Root Cause

The lab documented `hermes cron create` using `--schedule` and `--prompt` as flags.
The actual Hermes CLI signature (verified via `hermes cron create --help`) is:

```
hermes cron create [--name NAME] [--deliver DELIVER] [--repeat REPEAT]
                   [--skill SKILLS] [--script SCRIPT] schedule [prompt]
```

`schedule` and `prompt` are **positional** arguments, not flags. The flag-form
invocation never worked — this was a doc bug dating back to when the lab was
written.

## Fix

Rewrote all `hermes cron create` / `hermes cron add` invocations in course-site
docs from flag form to positional form:

| Before | After |
|---|---|
| `hermes cron create --name X --schedule Y --skill Z --prompt W --deliver local` | `hermes cron create "Y" "W" --name X --skill Z --deliver local` |

Also updated the Step 2 "What each flag does" table in LAB.mdx to reflect
positional args (`schedule` and `prompt` are no longer in the flags column;
they're documented as 1st and 2nd positional args).
