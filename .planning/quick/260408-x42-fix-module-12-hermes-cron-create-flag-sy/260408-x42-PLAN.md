<bug>
Module 12 lab (and related files) document `hermes cron create` using `--schedule`
and `--prompt` as flags. The actual Hermes CLI signature is:

  hermes cron create [--name X] [--skill Y] [--deliver Z] [--repeat N] [--script P] SCHEDULE [PROMPT]

where SCHEDULE and PROMPT are POSITIONAL arguments, not flags. Running the lab's
command as written produces:

  hermes: error: unrecognized arguments: --schedule --prompt ...

This blocks Lab 12 for every track at Step 2.
</bug>

<root_cause>
Lab content was authored against an incorrect mental model of the CLI. The flag-style
invocation never worked. Hermes `cron create` (and its `cron add` alias) has always
taken schedule/prompt positionally.

Verified via `hermes cron create --help`:
  usage: hermes cron create [-h] [--name NAME] [--deliver DELIVER]
                            [--repeat REPEAT] [--skill SKILLS] [--script SCRIPT]
                            schedule [prompt]
</root_cause>

<scope>
All files using `hermes cron create` or `hermes cron add` with the flag form need to
be rewritten to positional form. Grep inventory:

1. course-site/docs/module-12-triggers/lab/LAB.mdx
   - 6 cron create blocks (Track A/B/C + exploratory + cron-job examples)
   - 1 flag explanation table that documents --schedule and --prompt as flags
2. course-site/docs/module-12-triggers/lab/starter/cron-job-starter.yaml
   - Usage example in header comments (lines 6-11)
3. course-site/docs/module-14-capstone/capstone/ROADMAP-TEMPLATE.mdx
   - Line 117: `hermes cron add "[agent-name]" --schedule "..." --task "..."` — also
     uses invalid `--task` flag (should be positional prompt)

NOT touched:
- course-site/docs/module-12-triggers/quiz/QUIZ.mdx — the 2 mentions are prose
  references to the command name, not command invocations
- hermes webhook subscribe commands — those correctly use `--prompt` as a flag
  (verified via `hermes webhook subscribe --help`)
</scope>

<fix>
Pattern transformation:

OLD:
  hermes cron create \
    --name "NAME" \
    --schedule "CRON" \
    --skill "SKILL" \
    --prompt "TEXT" \
    --deliver local

NEW:
  hermes cron create "CRON" "TEXT" \
    --name "NAME" \
    --skill "SKILL" \
    --deliver local

Plus update the flag explanation table in LAB.mdx §Step 2:
  | `--schedule` | ... |   →   | `schedule` (positional, 1st arg) | ... |
  | `--prompt`   | ... |   →   | `prompt` (positional, 2nd arg)   | ... |

The ROADMAP template line 117 needs the same fix AND `--task` → positional prompt.
</fix>
