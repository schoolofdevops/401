# Module 14: Capstone — Demo and 30-Day Plan

**Duration:** 90 minutes
**Day:** Day 3, Final Session

## What This Module Is About

This is the culmination of the workshop. You have built a working domain agent, given it skills and tools, defined its governance boundaries, and connected it to production interfaces. Now you present it — and commit to deploying it.

The capstone has two deliverables. The first is a structured presentation: you demonstrate your agent against real or simulated data and explain the design decisions behind it. The second is a 30-day deployment roadmap: a week-by-week plan for taking your agent from the workshop environment to actual production use in your organization.

The templates and rubric in this module are the scaffolding for both deliverables.

:::info Solo Learner

If you are completing this course independently (Udemy), all capstone activities are designed for solo completion. Where the template says "team," substitute your individual work. The rubric scores individual output, not team collaboration. A screen recording or terminal log replaces a live demo. The 30-day roadmap is your personal deployment plan.

:::

## Learning Objectives

By the end of this module, you will be able to:

1. **Present an agent design with clear problem-agent-governance mapping** — articulate the problem you are solving, the pattern you chose, and why the governance spec is appropriate for the risk level
2. **Demonstrate a working agent against real or simulated data** — show the agent in operation, not just describe it
3. **Create a realistic 30-day deployment roadmap** — weekly milestones with success criteria and rollback provisions
4. **Self-assess using the evaluation rubric** — score your own capstone against defined criteria and identify what would make it stronger

## Prerequisites

- Module 10 completed (working domain agent)
- Module 13 completed (governance layer applied)
- Optionally: Module 12 (triggers/scheduling configured for production interface)

## How the Session Works

**Live workshop:** Teams of 3 present together. Each person takes one or two sections of the presentation. After each team presents, the cohort has 5 minutes for questions. The facilitator runs the rubric scoring as a group exercise.

**Udemy / solo:** You present to yourself, using the presentation template as a script. Record a screen capture if you want evidence of the demo. Run the rubric self-assessment honestly — it is a deployment readiness check, not a grade.

## What Comes After

The 30-day roadmap is not homework. It is a commitment. The agents built in this course are functional — they can be deployed to real infrastructure after the workshop. The roadmap gives you a realistic pacing plan so "I will do this after the workshop" does not become "I never did this after the workshop."
