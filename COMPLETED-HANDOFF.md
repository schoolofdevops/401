## Key Architecture Decisions (LOCKED)

These decisions are locked — do not change without explicit discussion:

1. **Context engineering > prompt engineering** — THE core philosophy. Expert vocabulary matters. "Prompt engineering" appears only as a contrast/negation teaching moment.

2. **Dual tool paths** — Claude Code (primary, Claude Pro/Team subscription) + OpenCode/sst (fallback, free providers: Gemini 2.5 Flash, Groq, OpenRouter, Grok). NOT Crush.

3. **Hermes profiles = agent definitions** — No Python. Agents defined via SOUL.md + config.yaml + skills/ directory.

4. **HERMES_LAB_MODE=mock|live** — Env var switching. `[MOCK MODE]` banner on output. Same skills work against both.

5. **Real systems first, mock as fallback** — All labs connect to real infrastructure when available. Mock data is clearly labeled and only for participants without access.

6. **Reference app as course backbone** — Rust microservices + Svelte dashboard + PostgreSQL on KIND. Used in Modules 1, 5, 6, and referenced in Modules 7-13.

7. **Docusaurus for all content** — All reading materials, labs, quizzes as MDX in course-site/. GitHub Pages deployment.

8. **Two-zone skill design** — Scripts Zone (deterministic CLI) + Agents Zone (reasoning/decisions).

9. **Diff-based governance** — L1-L4 as separate YAML files. `diff` to see what changes at each level.

10. **Dual format** — All content works for both live 3-day workshop AND self-paced Udemy. Labs are solo-completable.

11. **Guided generation labs** — Labs provide specific context/prompts for the AI tool at each step. Solution files for comparison. Participants see how structured input produces quality output.

12. **Track choice (not all)** — Participants pick ONE track per module (Module 5a: Helm or CI/CD, Module 6: Terraform or ArgoCD, Module 10: Database or FinOps or K8s).

13. **Module 5 split** — 5a (Structured Coding tracks) + 5b (AI Workflow Tools: GSD, memory, plan modes, context engineering, superpowers).

14. **No ArgoCD in foundation** — ArgoCD only in Module 6 Track B (where participants actively learn GitOps). Not pre-installed.
